# Браузерні тести

Набір Playwright перевіряє головну навігацію C1, загальнодоступні SEO-ресурси C7, асинхронне автодоповнення F2, блочний редактор C12 і карту C8. Тести не змінюють початкові дані, тому повторні запуски мають однаковий результат.

Для запуску потрібно виконати `pnpm install`, `pnpm exec playwright install chromium`, а потім `pnpm test`. Конфігурація автоматично запускає StudySpace.Web.
