# B9: кешування на рівні API

Запит `GET /api/documents/{id}` зберігає повний об'єкт відповіді в `IMemoryCache` на дві хвилини.

- Перша відповідь містить `X-Cache: MISS`.
- Повторна відповідь містить `X-Cache: HIT`.
- Запити PUT і DELETE видаляють відповідний запис із кешу.
- У кеші зберігаються DTO відповіді, а не сутності Entity Framework із відстеженням стану.

Реалізація демонструє шаблон cache-aside. Для розгортання кількох екземплярів застосунку сховище можна замінити на Redis без зміни HTTP-контракту.
