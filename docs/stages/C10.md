# C10: порівняння способів обміну даними

Сторінка `/Connectivity` отримує змінне значення сервера трьома способами одночасно:

- часте опитування кожні дві секунди;
- тривале опитування, під час якого запит очікує наступної версії даних;
- постійне з'єднання WebSocket.

Кожна панель показує кількість запитів або підключень, отримані повідомлення та затримку. Часте опитування є найпростішим, але створює запити навіть без змін. Тривале опитування зменшує кількість порожніх запитів, проте потребує повторного підключення. WebSocket підтримує постійне двостороннє з'єднання з найменшою затримкою для частих оновлень.
