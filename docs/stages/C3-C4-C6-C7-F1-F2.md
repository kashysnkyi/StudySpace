# C3, C4, C6, C7, F1, F2

- **C3:** GitHub Actions відновлює залежності, перевіряє форматування, збирає проєкт, запускає тести та створює контейнер для гілки `main` і запитів на злиття.
- **C4:** Багатоетапний Dockerfile створює компактний образ ASP.NET. Docker Compose зберігає базу SQLite та завантажені файли в іменованих томах.
- **C6:** Адаптивна головна сторінка на Bootstrap представляє StudySpace, показує стан проєкту та містить основні переходи.
- **C7:** Сторінки мають метаопис, Open Graph і канонічну адресу. Динамічні `robots.txt` і `sitemap.xml` містять загальнодоступні адреси документів.
- **F1:** Сторінка статистики використовує Chart.js для відображення кількості документів за статусами.
- **F2:** Автодоповнення на jQuery та AJAX починає пошук після трьох символів із затримкою 250 мс.
