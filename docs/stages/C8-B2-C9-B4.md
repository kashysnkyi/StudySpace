# C8, B2, C9, B4: інтеграції та пошук

- `/Map` відображає доступні робочі простори з координатами на карті Leaflet та OpenStreetMap. Фільтр плану оновлює дані карти.
- `WebhookNotificationService` надсилає події опублікованих документів до Telegram Bot API або на звичайний webhook, якщо інтеграцію налаштовано.
- Application Insights отримує стандартну телеметрію і події `DocumentCreated` та `DocumentUpdated`.
- `/api/search/documents` створює окремий для користувача індекс Lucene і повертає результати з оцінкою відповідності для автодоповнення.
