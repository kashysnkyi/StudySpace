# C18, F6: спільна дошка Canvas

Спільна дошка поєднує Canvas 2D і SignalR.

- Pointer Events підтримує мишу, перо і дотик.
- Нормалізовані координати зберігають положення ліній на екранах різного розміру.
- Користувач може вибрати колір і товщину лінії.
- Завершені штрихи надсилаються іншим користувачам тієї самої дошки.
- Обмежена історія на сервері дає новому користувачу змогу відновити поточний рисунок.
- Очищення дошки синхронізується між усіма відкритими вікнами.
