# C1: основа MVC

## Мета

Створити завершену частину StudySpace з інтерфейсом MVC, пов'язаними сутностями, посиланнями на файли та операціями CRUD.

## Реалізація

- `Workspace` містить колекцію сутностей `Document`.
- `Document` містить упорядковані `DocumentBlock` і `Attachment`.
- `Document.CoverImageUrl` зберігає зовнішнє посилання на обкладинку.
- Завантажений файл зберігається разом з адресою та метаданими.
- Контролери MVC підтримують створення, перегляд, редагування і видалення робочих просторів та документів.
- Entity Framework Core зберігає дані в SQLite.
- Початкові дані додаються лише до порожньої бази.

## Перевірка

```powershell
dotnet build StudySpace.slnx
dotnet test StudySpace.slnx --no-build
dotnet run --project src/StudySpace.Web
```
