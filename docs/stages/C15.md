# C15: браузерний File API

Форма вкладення використовує можливості браузера до надсилання файлу:

- перетягування отримує файли з `DataTransfer.files`;
- об'єкт `DataTransfer` передає вибраний файл у стандартне поле форми;
- `File.name`, `File.type` і `File.size` надають локальні метадані;
- `FileReader.readAsDataURL` показує зображення без надсилання на сервер;
- сервер окремо перевіряє розмір і розширення файлу.

Клієнтська перевірка покращує зручність, але не замінює перевірку на сервері.
