# C5, B1, QA1: REST API, пагінація та тести

## Кінцеві точки

| Метод | Адреса | Результат |
|---|---|---|
| GET | `/api/documents` | Сторінка коротких відомостей про документи |
| GET | `/api/documents/{id}` | Документ із блоками та вкладеннями |
| POST | `/api/documents` | Створення документа і відповідь `201 Created` |
| PUT | `/api/documents/{id}` | Оновлення документа |
| DELETE | `/api/documents/{id}` | Видалення документа і відповідь `204 No Content` |

Запит `GET /api/documents?skip=0&limit=20` повертає елементи, зміщення, обмеження, загальну кількість і посилання на наступну сторінку. Доступні фільтри `workspaceId` і `query`. Значення `limit` обмежене діапазоном від 1 до 100.

API повертає `200 OK` для успішного читання й оновлення, `201 Created` після створення, `204 No Content` після видалення, `400 Bad Request` для некоректних даних, `404 Not Found` для відсутнього документа і `409 Conflict` для однакових назв у межах робочого простору.
