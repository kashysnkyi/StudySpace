# F5, QA2: React SPA та браузерні тести

`src/studyspace-spa` - окремий клієнт Vite, React і TypeScript. Він отримує список документів, виконує пошук і редагування через JSON API, а також має стани завантаження, помилки й адаптивне оформлення. Команда `pnpm build` перевіряє типи та створює виробничу збірку.

Набір Playwright автоматично запускає ASP.NET і перевіряє головну навігацію, автодоповнення на основі Lucene, блочний редактор, карту, `robots.txt` і `sitemap.xml`. Тести зберігають трасування та знімки екрана лише у разі помилки.
