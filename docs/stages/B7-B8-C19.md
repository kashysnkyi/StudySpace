# B7, B8, C19: хмарні компоненти

- `StudySpace.Functions` - окремий проєкт Azure Functions із відкритою перевіркою стану та захищеним ключем формування дайджесту документів.
- `StudySpace.Web` публікує повідомлення `document.created` і `document.updated`, якщо налаштовано RabbitMQ. `StudySpace.Worker` послідовно обробляє повідомлення, підтверджує успішне виконання та відновлює з'єднання після недоступності брокера.
- `AttachmentStorage` використовує контейнер Azure Blob, якщо задано рядок підключення. Для локальної роботи файли зберігаються у файловій системі.
- Docker Compose об'єднує вебзастосунок, RabbitMQ, іменовані томи та фоновий обробник.
