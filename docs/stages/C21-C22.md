# C21, C22: помічник і MCP

Помічник робочого простору отримує доступний користувачу контекст документів і передає етапи обробки та відповідь через Server-Sent Events. Якщо налаштовано зовнішній сумісний сервіс, запит надсилається до нього. Без зовнішніх налаштувань використовується локальна відповідь на основі знайдених документів.

`StudySpace.Mcp` - окремий JSON-RPC сервер, що працює через stdio. Він підтримує ініціалізацію, пошук і виклик інструментів. Інструменти надають список документів, пошук Lucene та детальні відомості через REST API з урахуванням доступу користувача.
