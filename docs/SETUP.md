# Запуск і розгортання

## Локальний застосунок

1. Встановити .NET SDK 10.
2. Виконати `dotnet restore StudySpace.slnx`.
3. Виконати `dotnet run --project src/StudySpace.Web --urls http://localhost:5036`.
4. Відкрити головну сторінку, `/swagger`, `/Map`, `/Connectivity` та сторінки помічника і спільної дошки у робочому просторі з планом Premium.

Під час першого запуску застосунок виконує міграції EF Core і створює демонстраційний робочий простір. SQLite обрано для локального запуску без додаткового налаштування. Для використання іншої бази даних потрібно додати відповідний пакет EF Core та змінити `ConnectionStrings:StudySpace`.

## Секрети

Для локальної розробки рекомендовано використовувати `dotnet user-secrets` або змінні середовища. У хмарному середовищі значення потрібно зберігати у сховищі секретів платформи. Файл `appsettings.json` містить лише порожні значення налаштувань.

Адреса зворотного виклику Google має шлях `/signin-google`. У Google Cloud Console потрібно зареєструвати повну HTTPS-адресу, наприклад `https://your-app.example/signin-google`.

## Контейнери

Команда `docker compose up --build` створює:

- `web` на порту 8080;
- `rabbitmq` на порту 5672 і панель керування на порту 15672;
- `worker`, який обробляє повідомлення черги `studyspace.activity`.

База SQLite, завантажені файли та дані RabbitMQ зберігаються в іменованих томах.

## Розгортання в Azure

Потрібно створити Azure Web App, додати профіль публікації як секрет `AZURE_WEBAPP_PUBLISH_PROFILE` і встановити змінну репозиторію `AZURE_WEBAPP_NAME`. Після цього кожне оновлення гілки `main` запускає форматування, збірку, тести, складання контейнера й клієнтської частини, а потім розгортання. Робочі рядки підключення та секрети інтеграцій додаються в налаштування Web App.

Azure Functions розгортається окремо з `src/StudySpace.Functions`. Значення `StudySpaceApiUrl` має містити публічну адресу вебзастосунку.

## Перевірка MCP-сервера

Коли API запущено, можна надіслати JSON-RPC запит, завершений символом нового рядка:

```powershell
'{"jsonrpc":"2.0","id":1,"method":"tools/list","params":{}}' | dotnet run --project src/StudySpace.Mcp
```

Сервер виводить у стандартний потік лише повідомлення протоколу та підтримує `initialize`, `server/discover`, `tools/list` і `tools/call`.
